Logo sets used by the build (`go run ./tools/build -logo A|B|C`, default from `arc.config.json`).
Copied unchanged from `reference/logos/`. To add your own, create `logos/D/` with the same file names
(mark.svg, icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon-180.png, favicon-32.png)
and set `"logo": "D"`.
