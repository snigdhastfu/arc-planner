# Changelog

## v1.0.0
First release.
- Go core: planner with backwards scheduling around energy windows and daily goals, spaced revision for exams, forced/at-risk flags, replan diffs with partial approval and conflicts; quick-add parser; doodle matcher; ICS import/export with alarms; deterministic postcard layout.
- PWA: offline-first service worker with an update prompt, IndexedDB storage with a memory fallback, installable on iPhone and Windows.
- Screens: Today (Day Arc + Focus Card), Routines + Guided flow, Review plan, Horizon, Settings, onboarding, quick add, editor, doodle picker, tuck-in postcards, desktop two-column layout.
- Motion: spring engine, FLIP, View Transitions, draw-on doodles, line boil, hand-drawn outlines, reduced-motion support.
