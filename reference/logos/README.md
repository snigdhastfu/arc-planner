Three logo options (A sunrise, B sparkle tile, C squiggle A), drawn in the same hand-drawn style as the doodles. Default is B (arc.config.json). Per option: mark.svg (currentColor, 64x64 grid), mark-on-black.svg, icon.svg (rounded app icon), icon-maskable.svg, and ready PNGs: icon-192, icon-512, icon-maskable-512, apple-touch-icon-180 (full-bleed, iOS rounds it), favicon-32. The build tool copies the chosen set (see arc.config.json `logo`) into dist/. Do not redraw them.
